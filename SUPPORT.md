# Support

There is no support contract, SLA or warranty. The software is provided as is.

- **Bugs and questions:** open an issue. Best-efforts, no response commitment.
- **Security reports:** see `SECURITY.md`.
- **Licensing:** legal@ilovechicken.co.uk
- **Commercial enquiries:** support@algovoi.co.uk

A voluntary donation supports maintenance but does not buy support, priority or warranty.
