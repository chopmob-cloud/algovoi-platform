# Security policy

This is a free, unsupported release. There is no security-response SLA.

- Report vulnerabilities privately to security@algovoi.co.uk. Do not open a public issue for an
  unfixed vulnerability.
- Include the package, version, and a minimal reproduction.
- We will acknowledge best-efforts. We cannot promise a fix, a timeline, or a disclosure date.

Do not run an unpatched build in a regulated production environment without your own review.
